# Wajibika Kidigitali – Interactive Demo

An AI civic assistant that helps citizens in Tanzania understand how public money is used.
It works in Kiswahili and English, and reaches people with or without internet.

## What it shows
- **WhatsApp chatbot**: answers about council budgets, CAG reports, taxes and corruption reporting, using approved sources only. Accepts text, voice notes and photos.
- **Web AI**: the WAJIBU website (mobile view) with a floating button that opens Wajibika AI – chat history, photo questions, voice notes with voice replies, and talking by voice.
- **Feature phone**: USSD menu (`*123*08#`), SMS to WAJIBU, and a free voice line (`12308`) with daily limits.
- **WAJIBU Portal**: content approval, citizen questions, community alerts (SMS, voice, WhatsApp), users and roles, reports and exports (PDF, Excel, CSV).

## Built for
WAJIBU – Wajibika Kidigitali project in Kilosa, Mvomero, Mtwara DC and Mtwara MC.
Inclusive by design: for women, youth and persons with disabilities, and for people in low-bandwidth areas.

## Run it
It is a single HTML file. Open `index.html` in any modern browser. No setup is needed.
